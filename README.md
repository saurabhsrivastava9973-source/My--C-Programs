# My C Programs Collection

Welcome to my personal repository of C programming code! This repository serves as a sandbox for tracking my progress, mastering fundamental concepts, and improving my logic-building skills in the C language.

## 🛠️ Topics Covered
- **Basics:** Inputs/Outputs, Data Types, and Operators.
- **Control Flow:** If-Else conditions, Switch cases, and Loops (While, For).
- **Arrays & Strings:** Manipulating 1D/2D arrays and string operations.
- **Advanced (Optional):** Pointers, Functions, and Structures.

## 🚀 How to Run These Programs Locally

To compile and run any of these C programs on your computer, ensure you have a C compiler like `gcc` installed.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/saurabhsrivastava9973-source/My--C-Programs.git
   ```
2. **Navigate into the directory:**
   ```bash
   cd My--C-Programs
   ```
3. **Compile a program (e.g., replace `filename.c` with the actual file name):**
   ```bash
   gcc filename.c -o program
   ```
